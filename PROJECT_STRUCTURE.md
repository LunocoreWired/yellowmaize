## Execution order

```
1.  python partition_dataset.py          # Run ONCE — generates global manifest
2.  python create_bouncer_dataset.py     # Build 50k bouncer dataset
3.  python train_bouncer.py              # Train all 4 bouncer variants
4.  python sample_15000.py              # Sample 15k Tier 1 images
4b. python sample_gold_standard.py      # Export 300 images for Label Studio
    #   → annotate 100-200 more in Label Studio (target: 400-500 total)
    #   → Export JSON → data/gold_standard/annotations/annotations.json
4c. python train_yolo_detector.py       # Train YOLOv8n leaf detector + calibrate SAM2 QA
5.  python generate_tier1_masks.py      # SAM2 masking + QA  (v3: YOLO-guided prompts)
6.  python validate_masks.py            # Review QA report
6b. python sample_gold_standard.py      # Extract 300-image gold standard set
                                         # → images auto-copied to data/gold_standard/images/
                                         # → upload that folder to Label Studio
                                         # → annotate leaf silhouettes (polygonlabels)
                                         # → export JSON → data/gold_standard/annotations/annotations.json
6c. python validate_gold_standard.py --sam2-only  # Validate SAM2 masks vs human annotations
7.  python train_teacher.py             # Train all 4 teacher variants
6d. python validate_gold_standard.py    # Full chain: SAM2 → Teacher → Student IoU vs human
8.  python factory_master.py            # Generate pseudo-labels (all 4 modes)
9.  python train_student.py --stage 1   # Encoder ablation (5 variants, Mode B)
10. python train_student.py --stage 2   # Pseudo-label ablation (best encoder, 4 modes)
10b.python validate_gold_standard.py    # Re-run for final Student IoU (thesis table)
11. python select_best_pipeline.py       # Select best pipeline + canonical checkpoints
12. python evaluate_xai.py              # XAI comparison (3 methods)
13. python evaluate_severity.py         # Inter-rater severity check
14. python export_tflite.py             # Export best student to TFLite
15. python build_deployment_package.py  # Build Android deployment bundle
16. python generate_report.py           # Generate HTML evaluation report
```

## Dataset sources

| Dataset | Purpose | Source |
|---|---|---|
| Maize Imagery Dataset - Tanzania | Maize classes (HEALTHY/MSV/MLN) | Mduma (2023), Mendeley Data |
| Zenodo healthy + MSV samples | Additional maize samples | Zenodo |
| Intel Image Classification | Non-maize scenes | Kaggle |
| Natural Images | Non-maize objects | Kaggle |
| PlantVillage | Rice, sorghum negatives | Hughes & Salathé (2015), Kaggle |
| iNaturalist Philippines | Cogon grass, sugarcane negatives | iNaturalist API |
| Mendeley Maize-Weed Dataset | Field weed negatives | Espejo-Garcia et al. (2020) |
