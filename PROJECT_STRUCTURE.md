## Execution Order

```bash
pip install -r requirements.txt
pip install git+https://github.com/facebookresearch/segment-anything-2

# STEP 1 — Run ONCE. NEVER re-run after training begins.
python partition_dataset.py

# STEP 2 — Build Bouncer binary dataset
python create_bouncer_dataset.py

# STEP 3 — Train all Bouncer variants
python train_bouncer.py
python generate_charts.py --bouncer          # optional

# STEP 4 — Sample 15k Tier 1 images
python sample_15000.py

# STEP 4a — Export 501 images for human annotation (167 per class)
python sample_gold_standard.py
# → Import data/gold_standard/images/ into Label Studio
# → PASS 1: polygonlabels — trace full leaf silhouette for ALL 501 images
# → Export JSON → data/gold_standard/annotations/annotations.json

# STEP 4b — Train YOLO leaf detector + calibrate SAM2 QA threshold
python train_yolo_detector.py
# Reads annotations.json → derives bboxes from polygons automatically
# Requires ≥ 400 annotations. Outputs: checkpoints/yolo/best.pt

# STEP 5 — SAM2 masking [v3: YOLO-guided box prompts]
python generate_tier1_masks.py

# STEP 6 — QA review
python validate_masks.py
# → Inspect reports/tier1_overlays/ manually

# STEP 6c — Validate SAM2 vs human (before Teacher)
python validate_gold_standard.py --sam2-only
# Target: mean IoU ≥ 0.85

# STEP 7 — Train Teacher segmentation models
python train_teacher.py
python generate_charts.py --teacher          # optional

# STEP 6d — SAM2 + Teacher chain validation
python validate_gold_standard.py

# STEP 7b — Annotate symptom regions (second pass, same 501 images)
# In CVAT — labels: maize-leaf / msv-symptom / mln-symptom
# HEALTHY images: maize-leaf annotation only (no symptom regions)
# Target ≥ 400 MSV+MLN images. Export COCO 1.0 →
# data/gold_standard/annotations/symptom_annotations.json
python train_symptom_model.py
# → checkpoints/healthy_ae/healthy_ae_best.pth
# → checkpoints/symptom/symptom_teacher_best.pth

python validate_symptom.py                   # optional (Figures 4.16-4.18)

# STEP 8 — Generate pseudo-labels (~215k Tier 2 images, all 4 modes)
python factory_master.py

# STEP 8b — Visual QA of pseudo-masks (RECOMMENDED before Student)
python validate_factory.py --all-modes
# → Inspect reports/validate_factory_all_modes.html

# STEP 9 — Student Stage 1: encoder ablation (5 variants × Mode B)
python train_student.py --stage 1
# → Check logs/student_comparison_stage1.csv for best encoder

# STEP 10 — Student Stage 2: mode ablation (best encoder × 4 modes)
python train_student.py --stage 2 --encoder mobilenet_v2_cbam
python generate_charts.py --student          # optional

python validate_student.py                   # optional qualitative check

# STEP 10b — Final chain validation (SAM2 → Teacher → Student vs human)
python validate_gold_standard.py

# STEP 11 — Select best pipeline + promote canonical checkpoints
python select_best_pipeline.py               # auto-updates config.py

# STEP 12 — XAI evaluation
python evaluate_xai.py

# STEP 13 — Severity inter-rater reliability
python evaluate_severity.py --sample         # two raters fill severity_sample.csv
python evaluate_severity.py --analyze

# STEP 14 — Export to TFLite
python export_tflite.py

# STEP 15 — Build Android deployment bundle
python build_deployment_package.py

# STEP 16 — Generate HTML report
python generate_report.py
```

## Key Rules

- **Never re-run `partition_dataset.py`** after any training has begun.
- **Never delete `_manifest_hash.txt`** files while annotation or masking is in progress.
- **Stage 1 Student checkpoints go to `checkpoints/student/stage1/`** — prevents Stage 2 overwrite.
- **All image loading goes through `image_utils.py`** — never call `cv2.imread()` or `PIL.Image.open()` directly.
- **All DataLoaders use `collate_fn=safe_collate`** from `scripts/safe_collate.py`.
- **`sample_yolo_annotations.py` is deprecated** — do not run it.
- **`SYMPTOM_TEACHER_DEPLOYED = True`** in config.py — Factory uses Symptom Teacher for symptom masking. LAB fallback activates if checkpoints are missing.
