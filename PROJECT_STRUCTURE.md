## Execution Order

```
# Install dependencies
pip install -r requirements.txt
pip install git+https://github.com/facebookresearch/segment-anything-2

# ── STEP 1 ── Run ONCE. Never re-run after training begins.
python partition_dataset.py              # 10-step validation + 70/15/15 stratified global split

# ── STEP 2 ── Build bouncer binary dataset
python create_bouncer_dataset.py         # 25k maize + 25k non-maize = 50k balanced dataset

# ── STEP 3 ── Train all bouncer variants
python train_bouncer.py                  # gabor_lbp / MobileNetV2 / MobileNetV3-Large / EdgeViT-XXS
python generate_charts.py --bouncer      # bouncer comparison + training curves (optional)

# ── STEP 4 ── Sample Tier 1 images for SAM2 masking
python sample_15000.py                   # 15k stratified: 3k HEALTHY + 7.5k MSV + 4.5k MLN

# ── STEP 4a ── Export images for YOLO bounding-box annotation
python sample_yolo_annotations.py       # 501 images (167 per class) → data/yolo_annotations/images/
# → Import data/yolo_annotations/images/ into Label Studio (Object Detection task)
# → Draw ONE tight bounding box per image (primary leaf only). Label = "leaf"
# → Export YOLO format → data/yolo_annotations/labels/

# ── STEP 4b ── Export images for gold standard polygon annotation
python sample_gold_standard.py          # 501 images → data/gold_standard/images/
# → Upload data/gold_standard/images/ to Label Studio
# → Annotate at least 400 leaf silhouettes (polygonlabels task type)
# → Export JSON → data/gold_standard/annotations/annotations.json

# ── STEP 4c ── Train YOLO leaf detector + calibrate SAM2 QA threshold
python train_yolo_detector.py           # Requires ≥ 400 YOLO bbox annotations
                                         # Outputs: checkpoints/yolo/best.pt + logs/yolo_qa_calibration.csv

# ── STEP 5 ── SAM2 masking [v3: YOLO-guided box prompts]
python generate_tier1_masks.py          # float32 .npy + binary .png per image + tier1_qa_report.csv

# ── STEP 6 ── Review QA before Teacher training
python validate_masks.py                # QA stats + 5 qualitative overlays per class in reports/tier1_overlays/

# ── STEP 6c ── Validate SAM2 masks vs human annotations (run BEFORE Teacher)
python validate_gold_standard.py --sam2-only
# → Target: mean IoU ≥ 0.85 (GOLD_IOU_TARGET_MEAN)

# ── STEP 7 ── Train Teacher segmentation models
python train_teacher.py                  # resnet50 / efficientnet-b2 / mit_b2 / deeplabv3plus-eb2
python generate_charts.py --teacher      # teacher comparison + training curves (optional)

# ── STEP 6d ── SAM2 + Teacher chain validation vs human annotations
python validate_gold_standard.py         # Full run after Teacher training

# ── STEP 8 ── Generate pseudo-labels for all ~215k Tier 2 images
python factory_master.py                 # Writes all 4 modes simultaneously to data/pseudo_masks/

# ── STEP 9 ── Student Stage 1: encoder ablation (5 variants, Mode B fixed)
python train_student.py --stage 1       # V1–V4, V6 → checkpoints/student/stage1/

# ── STEP 10 ── Student Stage 2: mode ablation (best encoder, all 4 modes)
# Check logs/student_comparison_stage1.csv for best encoder first
python train_student.py --stage 2 --encoder mobilenet_v2_cbam
python generate_charts.py --student      # all student charts (optional)
python generate_charts.py               # regenerate all charts at once (optional)

# ── STEP 10b ── Final chain validation: SAM2 → Teacher → Student vs human
python validate_gold_standard.py         # Complete chain for thesis Chapter 3/4 table

# ── STEP 11 ── Select best pipeline + promote canonical checkpoints
python select_best_pipeline.py          # Auto-updates config.py STUDENT_BEST_VARIANT + STUDENT_FACTORY_MODE

# ── STEP 12 ── XAI evaluation
python evaluate_xai.py

# ── STEP 13 ── Inter-rater severity reliability
python evaluate_severity.py --sample   # Two raters fill in reports/severity_sample.csv manually
python evaluate_severity.py --analyze

# ── STEP 14 ── Export Student model to TFLite
python export_tflite.py                  # PyTorch → ONNX → TFLite (FP16)

# ── STEP 15 ── Build full Android deployment bundle
python build_deployment_package.py      # Bouncer TFLite + Student TFLite + metadata + README

# ── STEP 16 ── Generate HTML evaluation report
python generate_report.py               # → reports/evaluation_report.html (self-contained)
```

| Split | Ratio | Purpose |
|---|---|---|

Test-split images are **never** included in Tier 1 sampling, Bouncer positive class, Teacher training, or Factory processing.

## Key Rules

- **Do not re-run `partition_dataset.py`** after any training has begun. It regenerates `global_split_manifest.csv`, which invalidates Tier 1 sampling, gold standard annotations, and all checkpoints.
- **Do not delete `_manifest_hash.txt` files** in `data/tier1_raw/` or `data/gold_standard/images/` while annotation or masking is in progress. These locks prevent silent re-sampling that would invalidate Label Studio annotations.
- **Stage 1 student checkpoints go to `checkpoints/student/stage1/`** to prevent Stage 2 Mode B from overwriting them (same encoder + mode name collision).
- **All image loading goes through `image_utils.py`** — never call `cv2.imread()` or `PIL.Image.open()` directly. This ensures consistent EXIF orientation and channel order throughout the pipeline.
- **All DataLoaders use `collate_fn=safe_collate`** from `scripts/safe_collate.py` — if `__getitem__` returns `None` (corrupt image), the batch is filtered rather than crashing the worker.
